# विवाह बायोडाटा क्रिएटर | Marriage Biodata Creator

A modern, privacy-first **React + Vite** web app for creating beautiful Hindu / Marathi marriage biodata.

**Live Demo:** https://eldorado9604.github.io/bio-data-maker/

## Features

- ✨ **6 Beautiful Templates** for Hindu families (Classic, Modern, Traditional Om, Royal Gold, Minimal Hindu, Floral)
- 🕉️ Proper Hindu fields: Gotra, Rashi, Nakshatra, Manglik
- 📷 Photo upload support
- 🌐 Marathi + English language toggle
- 👁️ Live preview while editing
- 📄 One-click PDF download
- 💾 Auto-save draft in browser
- 🔒 100% client-side — data never leaves your device

## Tech Stack

React 18 + Vite + Tailwind CSS + html2canvas + jsPDF

## Local Development

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` automatically deploys to GitHub Pages via GitHub Actions.
